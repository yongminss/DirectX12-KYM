1. 게임 소개
   
   1-1. 3인칭 슈팅 게임으로 3개의 구역(일반, 화재, 몬스터)이 존재합니다.
   
   1-2. 일반 구역에 있는 몬스터를 처치하면 능력치를 강화할 수 있고 화재 구역에서는 아이템을 얻을 수 있습니다.
   
   1-3. 몬스터 구역에 존재하는 보스 몬스터를 처치하는 것이 최종적인 목표입니다.

   

2. 연구 목적

   2-1. DirectX 12에 대한 이해를 높이기 위해 프레임워크 리팩토링 작업 수행
   
   2-2. 뼈 구조를 가진 플레이어 및 몬스터 오브젝트의 애니메이션 구현
   
   2-3. 불꽃 효과 구현
   
   2-4. 조명 효과 구현
